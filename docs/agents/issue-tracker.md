# Issue tracker: Local Markdown

Issues and specs live under `.scratch/`.

- One effort per `.scratch/<feature-slug>/`.
- Its specification is `spec.md`.
- Tickets are individual files under `issues/`, numbered in dependency order.
- Each ticket records `Status:` and `Blocked by:` near the top.
- A ticket is available when its status is `ready-for-agent` and all blockers are complete.

Skills that publish work must write local Markdown; this repository has no remote issue tracker.
